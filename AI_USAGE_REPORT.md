# Mandatory AI Usage Report

**AI TOOL USED:** Gemini 3.1 Pro (High) via Antigravity Agent

**WHAT I ASKED AI TO DO:**
- Brainstorm product edge cases for a support ticket management system, which helped identify the need for a Pending Student workflow and SLA pause/resume handling.
- Assist with scaffolding the React/Vite frontend and Node/Express backend based on the architecture and requirements I defined.
- Assist with implementing MongoDB aggregation queries for Manager dashboard analytics and operational metrics.

**PROMPT THAT WAS MOST USEFUL:**
> "We need to handle the edge case where staff is waiting on a student. How do we ensure the SLA isn't breached unfairly?"

This helped identify the approach of pausing the SLA clock using `slaPausedAt` and tracking the accumulated paused duration using `totalPausedDuration`.

**CODE GENERATED BY AI: What part?**
The AI assisted with foundational CRUD routes, Mongoose schemas, API structures, and Tailwind CSS UI layouts based on the architectural requirements and implementation direction I provided.

**CODE I MODIFIED: What part?**
I directed the overall architecture and phased development approach. I defined the ticket lifecycle, strict `STATUS_TRANSITIONS` state machine, SLA behavior, role-based workflows, and Manager dashboard requirements. I also reviewed and modified the generated components and logic to ensure they matched the product requirements.

**AI OUTPUT THAT WAS WRONG:**
Initially, the AI attempted to create a simple Vanilla JavaScript application without a backend when I asked for a prototype.

**HOW I IDENTIFIED THE PROBLEM:**
I recognized that a `localStorage`-based Vanilla JavaScript prototype would not adequately demonstrate the required backend engineering aspects, including state-machine enforcement, role-based access, persistent ticket data, activity tracking, and SLA management.

**HOW I FIXED IT:**
I stopped that approach and redirected the implementation toward a structured React + Node.js + MongoDB architecture. I provided a phased development plan covering authentication, ticket management, status transitions, SLA handling, activity history, role-specific dashboards, and management analytics. The implementation was then developed and validated against these requirements.
